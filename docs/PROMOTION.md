# LumaView 推广素材与计划

## 定位

LumaView 是一款轻巧、便捷的 Mac 原生看图软件。打开图片，用方向键浏览同一文件夹；需要对比时，打开多个窗口。当前 v1.3.1 的 Apple Silicon 和 Intel 安装包各约 2 MB，支持 macOS 12 及以上。

## 可直接使用的文案

**一句话**

轻巧、顺手的 Mac 看图软件：打开图片，即可浏览整个文件夹。

**简短介绍**

看张图片，不必打开一整套图像管理工具。LumaView 是一款 Mac 原生看图软件，每个安装包约 2 MB。打开一张图片，就能用方向键浏览同一文件夹；放大、旋转、查看 EXIF 和多窗口对比，也都顺手。

**English**

LumaView is a lightweight native image viewer for Mac. Open an image, browse its folder with the arrow keys, and compare pictures in separate windows. Each installer is about 2 MB.

## 推广顺序

1. 以官网和 GitHub 为主要入口，首屏展示“约 2 MB”、系统要求、双架构下载和真实界面。
2. 适配 Mac 软件目录与开源项目索引：提交简短介绍、官网、源码、版本下载链接和真实截图；先核对各站提交规则及软件收录要求。
3. 面向 Mac 使用者的社区发布使用场景：方向键浏览、并排对比和多页 PDF 阅读。使用真实截图或短视频，说明设备与版本，附官方下载链接。
4. 按渠道记录发布时间、入口和反馈；定期对照 GitHub Releases 下载次数、仓库访问统计和反馈数量。平台展示或搜索收录变化不保证由推广直接造成。

发布前重新核对版本、安装包大小、系统要求与截图；“约 2 MB”指单个 DMG 的下载体积，不代表安装后占用或运行内存。速度和内存对比须在相同设备与测试条件下测量后再引用。
