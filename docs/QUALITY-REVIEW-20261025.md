# 2026-10-25 质量检查与优化记录

本轮由三个专项 agent 分别检查原生窗口与交互、图片解码与资源管理、测试与构建，再合并修改并复核。目标是修复可复现的问题、限制后台资源消耗，保持原生实现和较小体积。

**结论：44 项核心测试通过，r2 通用测试包已完成解锁后的关键功能人工复验；完整 UI 自动化仍受测试环境初始化失败阻塞，不应标记为全量自动化通过。** 本报告记录发布前验证；用户在了解验证结果后授权发布 v1.2.9，安装包由发布提交重新构建。已安装的应用未被替换。

## 已完成的修复

| 范围 | 修改及作用 |
| --- | --- |
| 窗口与菜单 | 关闭最后一个窗口后仍可用 ⌘O 打开文件；设置、关于和模态面板阻止图片命令误作用于后台窗口；全屏菜单正确切换进入/退出文案。 |
| 旋转与画布 | 全屏退出时按当前图片及旋转角度重算窗口；全屏动画期间忽略临时遮挡事件，避免把仍在显示的画布误释放。 |
| 图片信息 | 元数据读取进入限并发队列；请求关联当前图片与窗口生命周期，取消过期工作，避免旧结果回写；折叠工具栏使用有效弹框锚点。 |
| 图片显示 | 同一张图片升级解码清晰度时保留已经成功显示的画面；切图的临时预览在最终解码失败时清除，避免残留误导。 |
| 文件浏览 | 显式打开的隐藏图片不会被后续目录索引替换；Sketch 目录包按文档打开；切换目录取消旧元数据和打印准备；暂停画布时取消邻图预读。 |
| 目录错误反馈（续检） | 区分不存在、非目录和无读取权限；保留枚举错误，避免误报为空目录。扫描失败保留当前图，界面及读屏报告错误；目录、解码与打印状态分开保存，成功解码不会清除其他任务的错误。 |
| 解码与缓存 | EXIF 方向 5–8 正确交换显示宽高；缓存按实际像素行字节计费，超大单项不挤空整个缓存；热路径避免重复解析符号链接；处理极端尺寸和元数据数值。 |
| Sketch | 预览输出上限 64 MiB；候选路径共用 4 秒读取/解压期限；支持取消和子进程回收；目录包拒绝非普通预览文件；预览缓存随内部文件更新失效。 |
| 测试工具 | 使用主机架构运行测试、验证 Universal 两个架构；测试 bundle 与正式安装隔离；清理临时 LaunchServices 注册；像素验证缺少录屏权限时明确跳过。 |

未引入第三方运行时依赖。Sketch 子进程终止可能另有短暂回收等待；系统中的单次远程文件读取、ImageIO 解码不能保证被即时中断，不能把取消机制描述为硬实时保证。

## 尚待验证

- 此前文稿目录索引停在 1/1 的现象，在解锁后的同一路径重新打开与连续切图中未再复现。当时采样中系统 `open` 调用挂起的原因尚不能唯一归因，不能宣称已消除所有文件系统阻塞。另一个已确认的错误传播缺陷已修复并通过权限拒绝/恢复测试。
- 人工模拟目录不可读时，系统打开面板会先禁用“打开文件”，因此没有绕过该面板的校验强行打开。应用内部“直接文件可读、目录不可列举”的状态与读屏反馈由核心测试覆盖；临时目录权限已恢复。
- 完整 11 项 UI 自动化仍需在可用的 XCTest 环境补跑。此次桌面已解锁且可正常人工控制，但 Xcode 27.0 的 runner 在 60 秒后报 `Timed out while enabling automation mode`。尝试正常重启当前用户的 `com.apple.testmanagerd` 被系统完整性保护拒绝；未关闭保护、修改开发者权限或改动测试断言来绕过失败。只读检查显示 Developer mode 关闭，但尚未证明它就是超时原因。像素测试如缺少 runner 录屏权限会跳过；本次四个角度已由实际窗口截图补验。
- 没有在 Intel 真机和 macOS 13 实机运行；Universal 架构检查不等同于这些系统的功能验收。
- 本轮未做长时间 1/4/8 个 5K 窗口压力测试，也没有新的 RSS、显存、首图或切图速度基准；不宣称速度提升百分比。
- VoiceOver、真实 Finder 拖放、所有 RAW 相机格式和干净账户安装仍需专门验收。
