Fit, zoom, pan, and rotate. The status bar shows the current zoom level.

### Install and open LumaView

Open the downloaded DMG, drag  **LumaView.app**  into  **Applications** , then open it from Applications.

#### If macOS cannot verify the developer

Make sure the installer came from LumaView’s GitHub Releases. Try opening the app once, then go to security settings:

macOS 12 Monterey

System Preferences → Security & Privacy → General

macOS 13 or later

System Settings → Privacy & Security → Security

Find the LumaView message and click  **Open Anyway** . Authenticate, then choose  **Open** . If the button is missing, try launching the app again first.

If macOS says the app is damaged or will damage your computer, download it again from Releases or report the issue.
