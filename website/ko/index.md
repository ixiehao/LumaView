윈도우에 맞추기, 확대·축소, 이동, 회전을 지원합니다. 현재 확대 비율은 아래쪽에 표시됩니다.

#### 주요 이미지 형식

JPEG, PNG, HEIC, GIF, TIFF, WebP, RAW, Sketch 미리보기와 여러 페이지 PDF를 지원합니다.

### LumaView 설치 및 실행

다운로드한 DMG를 열고  **LumaView.app** 을  **응용 프로그램**  폴더로 드래그한 뒤, 해당 폴더에서 실행하세요.

#### 개발자를 확인할 수 없다는 메시지가 표시되면

LumaView의 GitHub Releases에서 받은 설치 파일인지 확인하세요. 앱 실행을 한 번 시도한 다음 보안 설정을 여세요.

macOS 12 Monterey

시스템 환경설정 → 보안 및 개인 정보 보호 → 일반

macOS 13 이상

시스템 설정 → 개인정보 보호 및 보안 → 보안

LumaView 관련 메시지에서  **그래도 열기** 를 클릭하고, 인증한 뒤  **열기** 를 선택하세요. 버튼이 보이지 않으면 먼저 앱 실행을 다시 시도하세요.

앱이 손상되었거나 컴퓨터를 손상시킨다는 메시지가 표시되면, 릴리스 페이지에서 다시 다운로드하거나 문제를 신고하세요.
