### 安装与首次打开

打开下载的 DMG，将  **LumaView.app**  拖入 **应用程序** ，然后从应用程序中打开。

#### 如果提示“无法验证开发者”

确认安装包来自 LumaView 的 GitHub 发布页，尝试打开一次后，进入系统安全设置：

macOS 12 Monterey

系统偏好设置 → 安全性与隐私 → 通用

macOS 13 及以上

系统设置 → 隐私与安全性 → 安全性

找到 LumaView 的提示，点按 **仍要打开** ，验证后选择 **打开** 。未看到按钮时，先再尝试启动一次。

若提示“已损坏”或“会损坏你的电脑”，请重新从发布页下载或反馈问题。
