### よく使う操作を、 すぐに見つける。

![中央に「ファイルを開く」だけを置いた LumaView のネイティブ歓迎画面](https://ixiehao.github.io/LumaView/assets/lumaview-welcome.png?v=20261017-alpha)

#### フォルダ内を移動

ツールバーまたは矢印キーで、同じフォルダ内の画像を前後に移動できます。

#### 細部まで確認

ウインドウに合わせる、拡大、パン、回転に対応。下部に現在の拡大率を表示します。

#### 主な画像形式に対応

JPEG、PNG、HEIC、GIF、TIFF、WebP、RAW、Sketch のプレビュー、複数ページの PDF に対応。

### インストールと初回起動

ダウンロードした DMG を開き、 **LumaView.app**  を **アプリケーション** にドラッグして、そこから起動します。

#### 「開発元を検証できない」と表示された場合

LumaView の GitHub リリースページから入手したことを確認してください。一度起動を試した後、セキュリティ設定を開きます。

macOS 12 Monterey

システム環境設定 → セキュリティとプライバシー → 一般

macOS 13 以降

システム設定 → プライバシーとセキュリティ → セキュリティ

LumaView のメッセージで **このまま開く** をクリックし、認証後に **開く** を選びます。ボタンが見当たらない場合は、もう一度起動を試してください。

「壊れている」または「コンピュータに損害を与える」と表示される場合は、リリースページから再ダウンロードするか、問題を報告してください。
