# Code of Conduct / 行为准则

## English

LumaView welcomes people who want to improve a small, respectful open-source
project. Be considerate in issues, pull requests, and reviews. Do not use
harassment, discrimination, personal attacks, sexualized language, or publish
private images, local paths, credentials, or security-sensitive details.

Keep feedback about the software and explain it in a way another person can
act on. Maintainers may edit, hide, or remove contributions that do not follow
these expectations. For a conduct concern, contact the project owner through
the [ixiehao GitHub profile](https://github.com/ixiehao) rather than opening a
public issue.

## 中文

LumaView 欢迎愿意共同完善这个小而克制的开源项目的人。请在 Issue、Pull Request
和评审中保持尊重；不得骚扰、歧视、人身攻击、使用性暗示语言，也不得公开私人图片、本地路径、凭据或安全敏感细节。

反馈请聚焦软件本身，并以他人能够据此行动的方式说明。维护者可编辑、隐藏或移除不符合这些原则的内容。如需反馈行为问题，请通过 [ixiehao GitHub 主页](https://github.com/ixiehao)联系项目所有者，而不要创建公开 Issue。
